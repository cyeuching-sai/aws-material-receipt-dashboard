## Public project presentation

`AWS_Material_Receipt_Dashboard_Public_zh-TW.pptx` is a public-safe GitHub edition based on the formal report deck.

- It retains the background, architecture, rule engine, rejection flow, data protection, verification, and cost-management content.
- It excludes names, employers, job titles, AWS account IDs, IAM users, credentials, and live API/CloudFront endpoints.
- Slides are flattened after redaction so the original screenshots cannot be extracted from the public deck. It is intended for viewing and presentation, not as an editable source.
- It describes only synthetic demo data and reproducible technical workflows.

Do not commit recording decks, company source workbooks, real work orders, or screenshots containing account information to this public repository.
